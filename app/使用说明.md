# 使用说明.md

## 组件概览

| 组件 | 位置 | 说明 |
|------|------|------|
| CanvasRenderer | `app/components/CanvasRenderer.tsx` | 画布渲染器：视频+Live2D+进度+LIVE 标识的实时合成 |
| CanvasRecorder | `app/components/CanvasRecorder.tsx` | 画布录制组件：捕获 Canvas 流并录制为 WebM |
| useCanvasRecorder | `app/hooks/useCanvasRecorder.ts` | Canvas 录制 Hook：提供 startRecording/stopRecording 等 |
| useVideoRecorder | `app/hooks/useVideoRecorder.ts` | 视频+Live2D 录制 Hook：捕获多源流并合并录制 |
| VideoPage | `app/VideoPage/videoPage.tsx` | 主页面组件：视频源切换/播放/录制控制 |

---

## 各组件详解

### CanvasRenderer
- **作用**：在 offscreen canvas 上实时合成视频帧、Live2D、录制进度圆点、LIVE 文字标识
- **Props**：`canvasRef, videoRef, live2dRef, isPlaying, isRecording, recordingDuration`
- **用法**：父组件传入 ref 对象引用，内部用 `useImperativeHandle` 暴露 `canvasRef.current`

### CanvasRecorder
- **作用**：捕获 Canvas 元素的视频流，使用 MediaRecorder 录制为 WebM (vp9 编码)
- **Props**：`canvasRef, width, height, fps, mimeType, autoDownload, onRecordingStart/Stop, onRecordingComplete`
- **用法**：在需要录制 Canvas 的场景直接挂载，配置完成后自动下载录像文件

### useCanvasRecorder Hook
- **作用**：基于 `CanvasRecorder` 封装录制控制逻辑，返回录制状态与方法
- **返回值**：`startRecording, stopRecording, isRecording, recordingDuration, getCanvas`
- **用法**：
  ```tsx
  const { startRecording, stopRecording, isRecording, recordingDuration } = useCanvasRecorder({
    canvasRef,
    width: 1920,
    height: 1080,
    fps: 30,
    mimeType: 'video/webm; codecs=vp9',
    autoDownload: true,
  });
  ```

### useVideoRecorder Hook
- **作用**：捕获视频元素、Live2D Canvas、音频元素的流并合并录制
- **返回值**：`startRecording, stopRecording, isRecording, recordingDuration, getVideoRef, getLive2dRef, getCanvas`
- **用法**：
  ```tsx
  const { startRecording, stopRecording, isRecording, recordingDuration } = useVideoRecorder({
    canvasRef,
    videoRef,
    live2dRef,
    captureAudio: true,
  });
  ```

### VideoPage 主页面
- **功能**：
  - 提供 6 个预置视频源切换
  - 播放/暂停控制
  - 录制启动与停止
  - 实时显示录制时长
  - 录制完成后自动下载 `.webm` 文件
- **Props**：`canvasRendererRef`（CanvasRenderer 的 ref 引用）
- **用法**：直接作为根组件渲染

## 快速集成

### 纯 Canvas 录制场景
```tsx
<CanvasRenderer
  canvasRef={canvasRef}
  videoRef={videoRef}
  live2dRef={live2dRef}
  isPlaying={isPlaying}
  isRecording={isRecording}
  recordingDuration={recordingDuration}
/>
const { startRecording, stopRecording, isRecording, recordingDuration } = useCanvasRecorder({ canvasRef });
```

### 视频+Live2D 录制场景
```tsx
const { startRecording, stopRecording, isRecording, recordingDuration } = useVideoRecorder({
  canvasRef,
  videoRef,
  live2dRef,
  captureAudio: true,
});
```

---

## 录制输出

- **格式**：WebM (vp9 编码)
- **尺寸**：1920×1080 (可在 Hook 配置中修改)
- **帧率**：30 fps（可配置）
- **保存路径**：浏览器自动下载为 `canvas-recording-<timestamp>.webm`
